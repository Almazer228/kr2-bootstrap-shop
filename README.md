
# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

Проект представляет собой учебный интернет-магазин, разработанный с использованием Bootstrap 5.

Цель проекта — изучение Bootstrap-сетки, готовых компонентов, адаптивной вёрстки и элементов интерфейса.

## Практическая работа №9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap через CDN;
- подключение css/custom.css;
- шапка страницы;
- Bootstrap-навигация;
- Hero-блок;
- блок преимуществ;
- сетка популярных товаров;
- подвал страницы.

## Практическая работа №10

Выполнена разработка страниц с использованием Bootstrap-компонентов.

Реализовано:

- единая Bootstrap-навигация;
- выпадающее меню dropdown;
- страница каталога catalog.html;
- карточки товаров через card;
- кнопки через btn;
- значки через badge;
- информационные сообщения через alert;
- модальное окно modal;
- страница товара product.html;
- таблица характеристик товара;
- форма заявки order.html;
- поля form-control;
- выпадающий список form-select;
- группа ввода input-group;
- чекбокс form-check;
- дополнительный компонент accordion.

## Запуск проекта

1. Скачать или клонировать репозиторий.
2. Открыть папку проекта в Visual Studio Code.
3. Открыть файл index.html через браузер или Live Server.

Для загрузки Bootstrap необходим доступ к интернету.
